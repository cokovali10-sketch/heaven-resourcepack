# Heaven Resource Pack

Combined server resource pack for **Heaven** (Purpur 1.21.11):

- **Stellarity 6.0.0** assets, unchanged (byte-identical files).
- **Heaven UI** add-on in its own `heaven` namespace (item models, button
  textures, background tile, small font) — additive only.

Nothing Stellarity owns is overridden: `assets/minecraft/font/default.json`
and `assets/minecraft/textures/gui/container/*` are the originals. This makes
the pack conflict-free while still adding fully custom GUI artwork.

## Files

- `heaven-combined-1.0.0.zip` — the pack the server serves.

## Server config

```
resource-pack=https://github.com/cokovali10-sketch/heaven-resourcepack/raw/refs/heads/main/heaven-combined-1.0.0.zip
resource-pack-sha1=40b2648e26b4c295ff9c137486c28d9358f95206
require-resource-pack=true
```
